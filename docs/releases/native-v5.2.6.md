# StremCompat Native 5.2.6 beta

> **Beta.** The stable version is StremCompat 4.5.6. The Native app installs next to it as a separate app.

## New

- **Subtitles by language, then by addon.** Each language once, the one you prefer first. In a language, the file's own subtitles come first, then each addon; an addon with several subtitles opens them, and a language or an addon with only one is chosen with one press. Back goes up one level.
- **Subtitles look like Nuvio's.** Regular letters with a solid outline all around, no shadow, at the size of Nuvio's TV app (larger than before).

## Fixed

- **Sources inside the player load completely.** The list showed only the first answer of the addons, often empty; it now grows as they answer, keeping the row in focus.

Everything else in [Native 5.2.5](https://github.com/StremCompat/webos/releases/tag/native-v5.2.5-beta) stays.

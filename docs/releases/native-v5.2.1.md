# StremCompat Native 5.2.1 beta

> **Beta.** The stable version is StremCompat 4.5.1. The Native app installs next to it as a separate app.

## Fixed

- **A Nuvio profile protected by a PIN opens faster and keeps its data.** Typing the PIN at start fetched the same profile's addons and collections again and emptied its new episodes and upcoming row. Entering the profile you already use now keeps everything.
- **The Magic Remote pointer hides as soon as you use the arrows,** and comes back only when you really move the remote, not with the hand's tremble. While it is hidden, its button works as OK. Settings > Interface > Magic Remote pointer can turn it off.
- **The app answers faster with the pointer on screen.** The focus followed every tremble of the pointer at once, asking the server for each card it crossed; it now waits for the pointer to rest.
- **Home backdrops show again.** With the TV busy making small copies, 5.2.0 could send a full-size backdrop, larger than the TV's graphics chip takes, and nothing showed.
- **Addons answer faster:** the limit of 8 connections to each addon's server is gone again.

Everything else in Native 5.2.0 stays: the Magic Remote pointer on every screen, the new PIN pad and the fixes of 4.5.0.

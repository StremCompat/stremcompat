# StremCompat 4.5.4

**The stable version, for Samsung only.** Install `StremCompat-v4.5.4-Samsung.wgt` over the version you have; your data stays. LG and Android TV have nothing new in this one and stay on 4.5.3.

## Fixed

- **The app opens on newer Samsung TVs.** On recent Tizen versions the TV accepted the request to start the app's local service and then never started it, so the app stopped on "StremCompat could not finish loading" (and the Native app on a black screen). The service now also starts the way Samsung documents for these TVs, the `wrt:service` module, and the app asks again while it waits. Older TVs keep starting it as before.

If it still does not open on your TV, please send a photo of the whole error screen (the small line starting with `APP_BOOT` says where it stopped) in [Discussions](https://github.com/StremCompat/samsung/discussions).

Everything in [4.5.3](https://github.com/StremCompat/samsung/releases/tag/v4.5.3) stays. What changed in each version is in [CHANGELOG.md](https://github.com/StremCompat/stremcompat/blob/main/CHANGELOG.md).

# StremCompat Native 5.3.0 beta

> **Beta.** The stable version is StremCompat 4.6.0. The Native app installs next to it as a separate app.

## New

- **Episode ratings with every metadata addon.** With addons like TMDB or AIOMetadata the episodes came without a rating; Cinemeta now completes them. The focused episode's line at the top shows its rating too.

## Fixed

- **Faster playback.** Since 5.2.8 the local server wrote a small file for every piece of a playing video; it now writes it at most once a minute.

Everything else in [Native 5.2.8](https://github.com/StremCompat/webos/releases/tag/native-v5.2.8-beta) stays.

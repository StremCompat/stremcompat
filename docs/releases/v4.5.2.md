# StremCompat 4.5.2

**The stable version.** It updates by itself from the Homebrew Channel and keeps your data. On LG webOS, choose the same package you use now: `StremCompat-v4.5.2-1080p.ipk`, or `StremCompat-v4.5.2-720p.ipk` for screens under Full HD.

## Fixed

- **An addon that stops answering no longer slows every Home.** A catalog that failed twice is not asked again for three minutes, instead of making each Home wait for its timeouts.
- **Covers and catalogs wait less for each other on the TV.** The local server has more helper threads for name lookups and disk reads (Node had four, shared by every request).

Everything else in [4.5.1](https://github.com/StremCompat/webos/releases/tag/v4.5.1) stays.

# StremCompat 4.5.7

**The stable version.** It updates by itself from the Homebrew Channel and keeps your data. On LG webOS, choose the same package you use now: `StremCompat-v4.5.7-1080p.ipk`, or `StremCompat-v4.5.7-720p.ipk` for screens under Full HD.

## Fixed

- **Subtitle changes show at once.** A new size, colour, background, opacity or delay in the player's subtitle menu waited for the next line to appear. The line on screen now changes as soon as you press, also with the video paused.

Everything in [4.5.6](https://github.com/StremCompat/webos/releases/tag/v4.5.6) stays, and the Native app stays on [5.2.6](https://github.com/StremCompat/webos/releases/tag/native-v5.2.6-beta). What changed in each version is in [CHANGELOG.md](https://github.com/StremCompat/stremcompat/blob/main/CHANGELOG.md).

# StremCompat 4.5.3

**The stable version.** It updates by itself from the Homebrew Channel and keeps your data. On LG webOS, choose the same package you use now: `StremCompat-v4.5.3-1080p.ipk`, or `StremCompat-v4.5.3-720p.ipk` for screens under Full HD.

## Fixed

- **The recommended source leads the list** (after a playback to continue), so the focus starts on the source the Best button would play.

The other fixes of this batch are for the Native app. Everything in [4.5.2](https://github.com/StremCompat/webos/releases/tag/v4.5.2) stays. What changed in each version is now also in [CHANGELOG.md](https://github.com/StremCompat/stremcompat/blob/main/CHANGELOG.md).

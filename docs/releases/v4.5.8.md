# StremCompat 4.5.8

**The stable version.** It updates by itself from the Homebrew Channel and keeps your data. On LG webOS, choose the same package you use now: `StremCompat-v4.5.8-1080p.ipk`, or `StremCompat-v4.5.8-720p.ipk` for screens under Full HD.

## Fixed

- **LG, newer TVs (webOS 10 / webOS 25):** the app stopped on "The app service did not respond" with RUNTIME_START_TIMEOUT. On these TVs the system held the app's start request back and never passed it to the app's service, so the local server was never started. The request now reaches the service at once, and the service also starts the local server as soon as it loads, so the start screen finds it by itself ([webos#14](https://github.com/StremCompat/webos/issues/14)). If it still does not open on your TV, a photo of the start screen helps a lot.

Nothing changes on Samsung and Android TV; this version keeps them level. Everything in [4.5.7](https://github.com/StremCompat/webos/releases/tag/v4.5.7) stays. What changed in each version is in [CHANGELOG.md](https://github.com/StremCompat/stremcompat/blob/main/CHANGELOG.md).

# StremCompat Native 5.2.3 beta

> **Beta.** The stable version is StremCompat 4.5.3. The Native app installs next to it as a separate app.

## Fixed

- **Your Nuvio profile's picture is back at the top of the side menu,** and you can select it: press Up from Search, or click it. It opens "Who is watching?" (or the account settings for a Stremio account), and it changes when you switch profiles.
- **Subtitles are grouped by language,** as in the web app: first the languages with how many subtitles each has, then the subtitles of that language. Languages also match now whatever code the file or the addon uses ("por", "pob", "pt-BR"), so the automatic choice finds your language more often.
- **The sources open with the recommended one first and in focus,** instead of somewhere down the list among the sources of the addon that answered last.
- **Sources come faster:** more network workers for slow addons, so a search left by an earlier screen no longer holds up the new one.

Everything else in [Native 5.2.2](https://github.com/StremCompat/webos/releases/tag/native-v5.2.2-beta) stays.

# StremCompat 4.5.6

**The stable version.** It updates by itself from the Homebrew Channel and keeps your data. On LG webOS, choose the same package you use now: `StremCompat-v4.5.6-1080p.ipk`, or `StremCompat-v4.5.6-720p.ipk` for screens under Full HD.

## New

- **All subtitles in one menu.** Subtitles now opens the list of languages, with the subtitles inside the file and those of your addons together. In a language, the file's own subtitles come first, then each addon. An addon with several subtitles in that language opens them; a language or an addon with only one is chosen with one press.
- **Subtitles look like Nuvio's.** The same look as Nuvio's TV app: regular letters with a solid black outline all around, no shadow, at Nuvio's usual size. On 1080p TVs they are larger than before; the size in Settings still makes them bigger or smaller.

## Fixed

- **Sources inside the player load.** The list waited for the slowest addon, and the menu closed by itself before anything came. Each addon's sources now show as they come, and the menu stays open while addons are still asked.

Everything in [4.5.5](https://github.com/StremCompat/webos/releases/tag/v4.5.5) stays. What changed in each version is in [CHANGELOG.md](https://github.com/StremCompat/stremcompat/blob/main/CHANGELOG.md).

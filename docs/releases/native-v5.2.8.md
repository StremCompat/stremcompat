# StremCompat Native 5.2.8 beta

> **Beta.** The stable version is StremCompat 4.5.9. The Native app installs next to it as a separate app.

## New

- **The rating of each episode,** beside its air date, when the metadata addon has it.
- **Titles open at once** with the name, picture and synopsis the card already knew, while the rest of the page comes.
- **The subtitle delay is in the subtitles list too,** once a subtitle is shown (it was only in the settings).

## Fixed

- **Continue after an update.** The local server keeps the recent sources, so Continue plays the same source after an update or a restart.

Everything else in [Native 5.2.7](https://github.com/StremCompat/webos/releases/tag/native-v5.2.7-beta) stays.
